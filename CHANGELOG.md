# Changelog

All notable changes to the Notes App project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-12

### Added
- Core responsive application architecture with ES modules and CSS custom properties.
- Full Markdown parser supporting headings, lists, tables, blockquotes, code blocks, and interactive task checklists.
- Live split-view Markdown preview with instant synchronized typing.
- Tag and category management with live sidebar counts and filter chips.
- Instant full-text search across titles, note content, and tags.
- Note status management: Pinning, Starred Favorites, Archiving, and Soft Delete / Trash.
- Color accent coding with 8 vibrant color schemes for visual organization.
- Multi-theme engine (Light, Dark, Solarized, Nord, and Sepia).
- Backup & Restore: JSON database export/import and Markdown file export.
- Keyboard shortcuts system with quick-action palette.
- Storage quota tracking and auto-save indicator.
- Browser test runner with automated unit tests for Note model and Markdown parser.
- Comprehensive user documentation, architecture specification, contributing guide, and MIT license.
