# Contributing to Notes App

Thank you for your interest in contributing to Notes App! We welcome contributions, bug reports, and suggestions.

## Code of Conduct
Please be respectful, collaborative, and considerate of all contributors.

## How to Contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes with clear, descriptive commit messages.
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

## Coding Standards
- Follow semantic HTML5 standards.
- Keep CSS modular and utilize CSS custom properties for theming.
- Write modular, readable, and well-commented vanilla JavaScript.
- Avoid introducing heavy third-party dependencies unless strictly necessary.
- Ensure all features function offline and persist gracefully.
