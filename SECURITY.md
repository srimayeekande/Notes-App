# Security Policy

## Supported Versions
All stable releases on the `main` branch are supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability within Notes App, please report it responsibly by contacting the maintainer via GitHub issues or directly at srimayeekande@gmail.com.

Please include:
- A description of the issue.
- Steps to reproduce the issue.
- Potential impact or threat model.

Thank you for helping keep Notes App safe and secure!
