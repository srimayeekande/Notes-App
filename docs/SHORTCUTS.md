# Keyboard Shortcuts Reference

Notes App provides keyboard shortcuts designed to maximize writing speed and efficiency.

| Shortcut | Action | Scope |
| :--- | :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>N</kbd> / <kbd>Cmd</kbd> + <kbd>N</kbd> | Create new note | Global |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> / <kbd>Cmd</kbd> + <kbd>S</kbd> | Force save active note immediately | Global |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> / <kbd>Cmd</kbd> + <kbd>F</kbd> | Focus global search input | Global |
| <kbd>Ctrl</kbd> + <kbd>\</kbd> / <kbd>Cmd</kbd> + <kbd>\</kbd> | Toggle navigation sidebar visibility | Global |
| <kbd>Ctrl</kbd> + <kbd>P</kbd> / <kbd>Cmd</kbd> + <kbd>P</kbd> | Toggle live Markdown preview mode | Editor |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> / <kbd>Cmd</kbd> + <kbd>B</kbd> | Format selected text with **Bold** | Editor |
| <kbd>Ctrl</kbd> + <kbd>I</kbd> / <kbd>Cmd</kbd> + <kbd>I</kbd> | Format selected text with *Italic* | Editor |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> / <kbd>Cmd</kbd> + <kbd>D</kbd> | Duplicate active note | Global |
| <kbd>Ctrl</kbd> + <kbd>Delete</kbd> | Move active note to Trash | Global |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Show keyboard shortcuts modal | Global |
| <kbd>Esc</kbd> | Close active modal / clear search input | Global |
